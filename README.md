# 合成大奶娃

用奶家人角色做的合成落下小遊戲：把兩個一樣的角色碰在一起，就會合成下一級，目標是合出奶娃。

## 合成順序

奶豆 → 奶蛋 → 奶鼠 → 奶貓 → 奶雞 → 奶茶 → 奶狗 → 奶粉 → 奶娃

## 玩法

- 滑鼠／手指左右移動瞄準，放開投下；鍵盤用 ← → 移動、空白鍵投下
- 角色超過盒口太久就結束
- 兩隻奶娃合體會一起消失並得到額外分數

## 本機執行

```bash
python -m http.server 8765
```

然後打開 http://localhost:8765 。放到 https 網址後可在手機上「加到主畫面」，當成全螢幕 App 離線遊玩。

## 檔案

- `index.html`：遊戲本體（物理引擎使用 [Matter.js](https://brm.io/matter-js/)）
- `shapes.js`：由圖片透明度算出的碰撞外框
- `assets/`：遊戲用的角色圖（從 `奶家人素材/` 裁切縮小）
- `manifest.json`、`sw.js`、`icons/`：手機安裝與離線快取
